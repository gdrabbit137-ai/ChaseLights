# ChaseLights Mobile — Capacitor APP shell (CL-APP-01)

Wraps `apps/web-v2` in a Capacitor 6 Android shell. All data is cloud-driven:
catalog, subject/evaluation bundles and language packs follow the published
bundle digests, so a new language or dataset ships as data, not as an app release.

## Layout

- `capacitor.config.json` — production: WebView serves `https://chaselights.app` (`server.url`), appId `com.chaselights.app`.
- `capacitor.config.dev.json` — local dev: WebView serves `http://localhost:8080` (run any static server on `apps/web-v2`), cleartext allowed. Dev only.
- `scripts/sync-web.mjs` — copies web-v2 static assets into `www/` (boot shell + last-known-good fallback). `www/` and `android/app/src/main/assets/public/` are generated, gitignored, and rebuilt by `npm run sync-web` / CI before packaging.
- `src/version-check.mjs` — startup digest check (`GET /api/v1/catalog/digests` → `{digest}`), background bundle download with SHA-256 fail-closed verification (same pins as `apps/web-v2/bundle-digests.mjs`), offline degrade to cache.
- `src/boot.mjs` — boot orchestrator: check → localized status → fire-and-forget background refresh on `new`/`first`.
- `src/i18n/` — flat camelCase keys aligned with web-v2's copy dictionaries (`app.mjs`), bundled `zh-TW`/`en`/`ja`; `registerLocale()` merges cloud language packs. UI copy is never hardcoded.
- `android/` — generated by `npx cap add android` (Capacitor 6).

## Commands

```sh
npm install
npm run sync-web     # refresh www/ from apps/web-v2
npm test             # node --test: version check / cache degrade / i18n / boot
npm run cap:sync     # sync-web + cap sync android
npm run cap:dev      # copy dev config into the Android project
```
