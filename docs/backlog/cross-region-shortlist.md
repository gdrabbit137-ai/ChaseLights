# 跨區比較清單（shortlist / compare）

**狀態**：backlog（owner 2026-11-27 裁示）
**來源**：資深風景攝影師體驗官 2026-11-26 體檢、E2E 混沌測試員（切地區動線）

## 問題（實測）

想「這週末去台灣還是日本」時，流程是：切地區 → 記住幾個景點 → 再切回來 → 忘記 →
再開一次。實際摩擦點：

- 切換地區時**地區篩選與搜尋字被清空**（日期與題材保留），回來要重設
- 題材清單隨日期／地區變動（今天只有夜景／倒影／瀑布，明天多出星空／日出／月光；
  日本有潮汐但沒有星空），沒有提示「這個題材在這一區不存在」
- 沒有並排比較，沒有「收藏後一起看」
- 「我的最愛」要登入（訪客不能用）

## 提議做法

1. **比較匣**：卡片 ⋯ 選單加「加入比較」，最多 4 個；底部浮出比較列，
   開啟後是一張對照表（題材、時段、等級、WMO、氣溫、能見度、海拔、距離）。
2. 比較匣**跨地區有效**（存在 localStorage），切地區不清空。
3. 訪客也能用比較匣（不需要帳號），登入後可同步。
4. 篩選狀態在切換地區時保留（地區本身除外），並在題材清單標示「此區無此題材」。

## 驗收標準

- 從首頁把台灣 2 個、日本 1 個景點加入比較，切換地區後比較匣仍在，內容不變。
- 對照表在 393px 寬度可橫向瀏覽（單欄堆疊，不是被切掉的表格）。
- 比較匣關閉後不影響卡片列表狀態；重整頁面後內容仍在（localStorage）。

## 風險

- 跨地區比較容易讓人誤以為「同一趟旅程」，需在表頭標明各景點的時區與地區。
