# R4 Place-first Beta Release

This public beta introduces the R4 Place → Photography Opportunity presentation while preserving the existing production weather score for ranking.

Visible changes:
- Place cards show the number of curated photography Opportunities and up to two Opportunity names.
- The 96H detail modal shows all curated Opportunities for that Place.
- Preview-ready Opportunities can show whether at least one hourly window on the selected date matches their runtime diagnostic.
- Pending/prototype/hold/data-insufficient Opportunities are labeled instead of receiving a fake R4 score.
- tw-063 翟山坑道 is retired from the active catalog.

This is intentionally a UI/data-model rollout first; runtime modules will continue to expand after launch.
