## 0. 現狀實測（390px 手機）

| 項目 | 實測值 |
|---|---|
| 每張小時卡高度 | **217–218px**（目標 ≤120px） |
| 24 小時卡總滾動長度 | 一天卡片區 ≈ 5,600px；三天 192 卡總高 42,526px |
| 每卡指標數 | **8 欄全部平鋪**：氣溫／能見度／低雲／中雲／高雲／風速／凝結高度／濕度 |
| 能見度文案 | 「≥ 24 km（資料上限）」佔一整行方框（primary 標記） |
| 雲量 | 「低雲 100%」「中雲 0%」「高雲 100%」三行獨立方框，無口語化 |
| 狀態 | 「⚠️ 未符」文字行，無色彩語義承載；與同卡內容無矛盾關聯 |

### 三大痛點（owner 打回）

1. **資訊重複矛盾**：卡片同時顯示「未符徽章」與「○一般拍攝」——判定未符的題材又出現「一般拍攝」合格標記，攝影師無法判斷到底能不能拍。
2. **原始指標當文案**：能見度「≥24km(資料上限)」是資料管線的上限標記，不是給攝影師讀的；「雲 L/M/H 5/100/100」是密碼，不是口語。
3. **⋯詳情按鈕收了又開**：展開狀態在滾動/重渲染時丟失，反覆展開很煩。

## 1. 資訊層級重定義

### 1.1 層級模型（攝影師唯一問題：「幾點？能不能拍？條件如何？」）

| 層級 | 內容 | 語義 | 顯示 |
|---|---|---|---|
| **L1 時刻** | 15:00 | 中性 | 固定左欄，14px semibold |
| **L2 主狀態** | 「能拍：日落」或「不宜：高雲 100%」 | 唯一狀態，唯一一行 | 14px semibold，色帶承載 |
| **L3 輔助氣象** | 「晴・低雲 5%」「能見度極佳」 | 12px 灰，一行 | text-2 |
| **L4 原始數值** | 氣溫/風速/濕度/凝結高度/中高雲 | 全部收進「詳細氣象」展開 | 預設收起 |

### 1.2 口語化映射表（RD 直接落地）

| 原始 | 口語化文案（zh-TW） | 顯示條件 |
|---|---|---|
| `visibility ≥ 24` | **「能見度極佳」** | 任意時 |
| `visibility 12–24` | 「能見度良好」 | 任意時 |
| `visibility 6–12` | 「能見度普通」 | 任意時 |
| `visibility < 6` | 「能見度差」 | 任意時 |
| `L/M/H 5/5/5` | **「晴・雲 5%」** | 總雲量 ≤10% |
| `低雲 0%`、中高雲合計 <30% | 「晴・低雲 0%」 | 日落/日出時段 |
| `低雲 30–70%` | 「多雲・低雲 43%」 | 日落/日出時段 |
| `低雲 >70%` | 「陰・低雲 100%」 | 任意時 |
| `降水 >0` | 「小雨」/「大雨」 | 任意時 |

> 「≥24 km（資料上限）」**禁止**在卡片層出現；僅在「詳細氣象」展開中以 tooltip「24 km 為資料上限」顯示。

### 1.3 去重規則（規則 2）

- **未符時，卡片不顯示「一般拍攝」**——「一般拍攝」是 `verdict_suitable`/`verdict_chance` 之外的合格徽章，但當「未符」徽章（⚠️）與「一般拍攝」並列時，攝影師無法判斷。
- **規則**：一卡一行主狀態＋一行輔助。主狀態行只有一種判斷（能拍/有機會/不宜/非建議時段），輔助行只有口語化氣象（雲/能見度/雨）。兩者不合併，不重複。
- **「一般拍攝」**僅在「符合時段（✅）」且「有機會時段（🟡）」**之外**，作為額外徽章顯示；若該小時未符（⚠️ 或 🕒），該徽章**隱藏**。

## 3. 全版面節奏（24 小時 24 卡掃描性）

### 3.1 布局：時間軸左欄固定

```
┌──────┬──────────────────────────────────────┐
│ 15:00 │ [能拍：日落]                        │
│ 15:00 │ 晴・低雲 5% ・ 能見度極佳             │
│      │  📋 詳細氣象 ▾                       │
├──────┼──────────────────────────────────────┤
│ 16:00 │ [能拍：藍調]                        │
│ 16:00 │ 多雲・低雲 43% ・ 能見度極佳          │
│      │  📋 詳細氣象 ▾                       │
├──────┼──────────────────────────────────────┤
│ 17:00 │ [不宜：高雲 100%]                   │
│ 17:00 │ 晴・低雲 0% ・ 能見度極佳             │
└──────┴──────────────────────────────────────┘
```

- **左欄固定**：時刻 15:00/16:00/17:00… 靠左對齊（固定 64px 寬欄），右側為主狀態＋輔助氣象；滾動時左欄固定不動。
- **主狀態色帶**：卡片左側 3px 縱向色帶（綠/黃/灰紅）承載「能不能拍」的判斷，不用 emoji。

### 3.2 掃描性：24 小時掃描

- **24 小時全掃**：24 卡總高度由 5,600px 壓縮至 ~1,800px，一屏（844px）可見 4–5 卡，視覺掃描時間 < 2s。
- **色帶掃描**：色帶承載狀態色，掃描時不用讀字，直接判斷「能不能拍」。
- **時間軸左欄**：時刻固定，掃描時不因滾動而偏移，可快速對位。
