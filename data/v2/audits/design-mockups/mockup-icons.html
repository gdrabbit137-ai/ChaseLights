全站 icon 系統 — Lucide 套用示範

Lucide v1.73.0 · 24 grid · stroke 2 · stroke=currentColor（顏色一律繼承文字 token，語義色不另行上 icon）· path 原樣內嵌本檔，零 CDN 依賴。三語標籤：zh-TW / EN / 日本語。

1 · 卡片三鈕 — 題材｜地圖｜天氣圖

左一「題材」開題材面板（DESIGN-6b 定案）、「地圖」開外部地圖、「天氣圖」開天氣圖。icon 14px、與 12px 標籤同 baseline。

選用：gallery-thumbnails（題材＝題材縮圖面板）· map-pin（單點定位）· cloud-sun（天氣＋拍攝雙語義）。
任務原案 frames 不存在於 Lucide 1.73（lucide-static icons 目錄查證 404，僅有 frame） — 備選 layers（題材分層語義，按鈕語境略抽象）。

2 · 導覽 — 卡片／天氣圖／提醒／會員

20px icon ＋ 13px 標籤；active 態文字變 text-1、icon 轉綠（語義=所在區可用）；未選 icon 灰 text-3。會員維持右上會員入口（DESIGN-3b）。

3 · 卡片內 — ★ / 🔔 / 海拔 / 太陽 / 溫度計

卡片本體不動（DESIGN-6b），僅將 emoji 換 Lucide：★=最愛（amber）、🔔 三態=bell / bell-ring / bell-off、pills 內 海拔=mountain・太陽=sunrise・溫度=thermometer，icon 色跟 pill 文字（text-3）走。

6 · token 上色 — currentColor 語義規則

icon 不自帶顏色：stroke=currentColor，色值＝所在文字 token。語義色只表達狀態，絕不裝飾。

text-3 中性
text-2 可按
green-text 所在區
amber-text 最愛
amber 已設提醒
grey 暫停
red-text ✗ 語境
規則：① 同 icon 可因語境變色（bell-ring 未讀=amber、停用=grey）；② blue 僅連結（站外連結的 map-pin 為 blue）；③ 14px（按鈕/pill）、16px（行內）、20px（導覽）三檔，24 僅展示。

7 · 品牌專屬件 — 建議自繪（Lucide 無對應／語義不符）

以下 5 件建議自繪 SVG（24 grid、stroke 2、currentColor，與 Lucide 同構混用無違和）；其餘全站一律 Lucide，不再自繪。

① 品牌標誌／App icon

DESIGN-8 三案（logo-1/2/3.svg）待 owner 選定；adaptive 三層＋favicon 全套同步產出。

② 地圖景點光點 marker

WeatherGrid 瓦片上的 tier 發光點（✓/○/✗ 色＋光暈），須在 16px tile 縮放下可讀 — Lucide map-pin 無狀態色與發光。

③ 光害／暗空指標

lightbulb 語義是「點子」；自繪「城市光暈射向天際」小圖，表達 Bortle/光害等級。

④ 雲海

cloud-snow 的雪點誤導（雲海≠下雪）；自繪「雲層疊山稜」雙形，雲海/低雲 80%+ 條件語義。

⑤ 星軌／銀河

stars 是泛星空；星軌（同心弧）與銀河（斜向星雲帶）建議各一顆，21 種題材短名中僅這兩個無對應。

設計說明（DESIGN-8 決策記錄 — 給 owner 與實作 RD，不進產品碼）
  • icon 源：Lucide lucide-static v1.73.0（ISC 授權可內嵌）。本頁 path 全部原樣取自該版本 icons 目錄（curl 拉取核對），非憑記憶手寫。
  • frames 查證：任務原案「題材=frames」在 1.73.0 不存在（unpkg/jsdelivr 均 404；目錄僅 frame.svg）— 以 gallery-thumbnails 定案、layers 備選，已列入對照表。
  • currentColor 契約：icon 顏色永遠繼承文字 token — 三語切換、深淺主題、語義改動零 icon 特例；紅只出現在 ✗ 語境，避免「紅鈴鐺」誤讀。
  • 尺寸階梯：14（pill/按鈕）/ 16（行內）/ 20（導覽）／展示 24；stroke 恆 2（Lucide 標準），縮到 14px 不加粗以維持單色重量一致。
  • tier 記號不 icon 化：✓/○/✗ 是全站掃描契約（tab/徽章/計數同源），文字＋契約色已是單字元最強掃描件；icon 化反而引入第二套語言。
  • 自繪邊界：僅 §7 五件自繪；其餘 emoji 全量清理為 Lucide。自繪件同構（24 grid / stroke 2 / currentColor），RD 可直接以 lucide-angular/vue 套件外掛 custom icon。
