### 1.1 P1 單一列表原則（mockup 已呈）

- 自訂點與官方景點**同一張卡片、同一評估層**：同 subject-cards tier 語義（✓○✗，時間感知）、同 24h 色帶、同評分 ★chip、同「題材｜地圖｜天氣圖」三鈕。**不另立「我的清單」平行頁**——平行頁會造成第二真相源與雙倍維護面。
- 差異只有三處：①標題行一枚**灰色「私人」徽章**（`--cl-grey`，永不借用綠/黃/紅語義色——✓○✗ 仍是唯一決策階層）；②⋯選單（✎編輯／🎞 掛題材·條件／⬆ 提名升級官方／🗑 刪除）；③篩選切換**全部｜官方｜私人**（挨著地區選單）。
- 計數誠實：標題行「共 460 個官方景點＋你的 3 個私人點」；檢視切換顯示 全部 463＝官方 460＋私人 3——**永不加錯**；✓○✗ tier tabs 與檢視切換、地區選單三者疊加過濾。
- 地圖同顯示：官方釘＝tier 色釘；私人釘＝**灰釘＋白環**（雙編碼，色盲可辨）；地圖不隱藏私人點——同一空間認知。
- 新增流程＝**按鈕彈窗**（560px；390px 全幕）：名稱 → 地圖釘點（點圖落釘與 lat/lng 手鍵雙向同步，**全球任意經緯度**皆可，海洋/極區亦可）→ 海拔（**DEM 自動**，Elevation API 唯讀帶入，使用者不手填——防海拔漂移）→ 時區（**自動**，IANA 名＋UTC 偏移唯讀顯示，日出/時窗就地計算）→ 建立 → 接著掛題材/條件。兩步完成，不離開列表。

### 1.2 P1 題材掛載：一般題材＋CL-UI-99 五組參數

- 自訂點掛**一般題材**（21 種短名同一套字典）；一般基準（✓○✗）照算——私人點不做特殊題材的即掛即用（特殊題材走人工審，§5.2）。
- 自訂條件＝**重用 CL-UI-99 已上線引擎**（merge `fd02537b3`：migration 0009＋cron 自訂模式＋kv_distill weather_rows），同規格同驗證的五組參數：**低/中/高雲 0-100%、降水上限 mm/h、能見度下限 km、風速上限 m/s、時間窗 HH:MM（跨午夜可）＋提前量分鐘**。寬鬆預設，只列有調的參數（「低雲≤20%・能見度≥10km・05:00–07:00」摘要規則同款）。
- **提醒/評分/推播共用現行機制，零新後端路徑**：提醒走同一 notify cron 引擎（私人點＝多一列自訂座標）；評分走同一 `feedback`/`rating_agg` 管線（DESIGN-7，一人一票/信任階梯/簇上限全適用）；推播走同一佇列與節流位。私人點的免費功能邊界與官方點一致（§3.3）。

### 1.3 P1 刪除語義（不可回復，彈窗明列）

刪除私人點＝**提醒一併停用、評分紀錄一併移除、指向此點的最愛清除**——彈窗以紅系確認並明列受影響的附掛資料數（「提醒 1 條・評分 1 則」）。提名中的點先撤提名再刪。

## 2. 額度保險（owner 裁示）

### 2.1 個人額度：25 → 50 點（裁示）

- 「點」＝自訂內容額度單位（1 點＝1 個私人景點；P2 後 1 個自訂題材模板同計一池）。
- 原草案每人 25 點 → **owner 裁示改 50 點**（Premium；見 §3）。額度誠實顯示：標題行 quota chip「私人點 3/50 · Premium」＋新增彈窗同值；滿額時 ＋按鈕轉灰＋升級/清理連結，**不突襲**。

### 2.2 公平使用軟降頻（三段，fail-open 為預設、fail-closed 為剎車）

| 級距 | 觸發 | 動作 | UI 誠實標示 |
|---|---|---|---|
| 正常 | — | 隨官方批次刷新 | 「資料更新：每 6 小時」 |
| 軟降頻 1 | 個人用量 **前 1%** | 重新評估間隔放寬為**每日**一次 | 「節能模式」banner：說明原因＋「資料更新：每日」＋恢復條件 |
| 軟降頻 2 | 前段仍高（持續前 0.1%） | 再放寬為**每 2 日**一次 | 同上，標示「每 2 日」 |
| 全域剎車 | 全站用量達 Open-Meteo 額度 **70%** | 全域刷新間隔放寬 **10%**（所有會員一致，含公告） | 站務公告＋各頁「資料更新」頻率實值同步改 |
| 硬停 | 達 90% | 停止非核心刷新（**保留提醒觸發取數**——notify 是付費核心承諾，永不降） | 全站警示 |

- **「節能模式」必須誠實標**：任何降頻都在卡片/彈窗顯示實際「資料更新」頻率——**絕不靜默降質**（顯示層永遠知道資料多新，使用者自行判斷）；這是全站誠實標示原則（§5）在額度面的延伸。
- 軟降頻只影響**取數頻率**，不影響：提醒觸發的即時取數、評分/回報等 UGC 寫入、tier 計算正確性。

## 3. 分級路線（Free / Premium / Pro）

### 3.1 定價與額度

| 級 | 額度（點） | 定價 | 名額 | 備註 |
|---|---|---|---|---|
| **Free** | 1 點 | NT$0 | — | 完整流程可體驗（1 個私人點＋全部五組參數＋提醒/評分）；額度**上線前定死**（DESIGN-7 原則：永不收回既有免費功能） |
| **Premium** | 50 點 | NT$1,200/年 | 不限 | — |
| ├ 早鳥 | 50 點 | **NT$690/年** | **限 100 名** | 綁帳號，續約價 NT$1,200 |
| ├ 終身 | 50 點 | **NT$3,490** | **限 50 名** | 一次性；綁帳號 |
| **Pro** | 200 點 | NT$2,400/年 | 由需求觸發 | **不預先開賣**——當 Premium 會員「撞上限」（觸及 50 點上限）人數達門檻（建議 ≥20 人）才開 Pro SKU；早開＝定價訊號錯誤、晚開＝流失可承認 |

### 3.2 付費邊界（沿用 DESIGN-7 裁示）

- free＝探索與規劃（目前全站功能）；paid＝深度與自動化（私人點額度、自訂條件額度、提醒 3→20 條 reserved、iCal 訂閱、更長預報視程）。自訂條件的 KV gate（DESIGN-7 已設計：現行未閘，付費上線時翻旗）對私人點同樣適用。
- GRANDFATHER：額度下調從不回收已建立的私人點；只鎖「新增」。

### 3.3 觸發時程建議

```
P1 上線（Free 1 點全量體驗）→ 觀察轉換 → Premium 開賣（早鳥 100 → 一般價）→
監測「撞上限人數」→ ≥20 人 → Pro 開賣（NT$2,400/年 200 點）
```

## 4. 營運成本欄

### 4.1 Open-Meteo 商業授權（P1 上線的前置條件）

| 項 | 內容 |
|---|---|
| 方案 | **API Standard：1M calls/月**（含 Weather Forecast / Air Quality / **Elevation（DEM 海拔）** / Geocoding / Flood / Marine；Historical/Ensemble 需 Professional） |
| 實價 | **以 Stripe 結帳頁確認為準**（訂閱經 Stripe 收取） |
| 外界引用 | 約 **€29 起**／月（Open-Meteo 官方公告 US$29/月＝Standard 1M） |
| 免費層禁令 | Free/Open-Access 300k calls/月**不得用於商業用途**（600/min、10k/日上限）——**P1 上自訂景點前必須完成商業授權切換**（customer-api.open-meteo.com＋API key） |

### 4.2 用量估算（示意，上線後以實測校準）

- 現況全站用量 ≈ Standard 額度的 **5.5%**（≈5.5 萬次/月）。
- **300 付費會員**情境 → 估算 **28 萬次/月（≈28% 額度）**：自訂點取數與官方同一批次快取管線（per-location 節流；region ingest 分 job 避開 per-IP 額度——CL-INT 既有教訓）＋個人自訂條件的 KV distill 行不新增 API 呼叫。
- DEM 海拔＝Elevation API（Standard 內含，私人點建立時一次性呼叫）；時區自動＝IANA 本地運算，**零外部呼叫**。
- 結論：**300 付費會員規模下 Standard 單一方案足夠**；剎車機制（§2.2）保證永不撞 1M 牆。成本底線：Standard 年費（依外界引用 ≈€348/年）< 100 名早鳥收入（NT$69,000/年）——**單一 SKU 即涵蓋資料授權成本**。

## 5. 資料品質誠實標示與特殊題材人工審

### 5.1 冷門區低品質標籤（誠實標示原則）

- 自訂點可能在觀測稀疏區（高山/離島/海外冷門區）：其評估用模式資料品質低於官方景點平均時，卡片與彈窗（**同源同一標籤**）出示**「低品質資料」灰標籤**＋tooltip 說明原因（模式解析度/觀測密度不足）——**不出示假精度**，與「未符必帶短因」「數值永不省略號」同一誠實家族。
- 460 官方景點的既有品質分級沿用；私人點品質欄由座標所在格點自動判定，使用者不手選。

### 5.2 特殊題材人工審

- 自訂點**一般題材即掛即用**（21 種短名＋一般基準，引擎現成）。
- **特殊題材**（極光、季節限定、非 21 種的自訂模板——P2 起）**必須人工審**後才供評估：審「題材定義可運算性（有明確物理門檻）＋資料源可得性」。進 DESIGN-7 審閱佇列，admin 三鍵處置；不通過退回「僅一般基準」。
- 提名審核（P3）四關不變：位置驗證／去重／命名規範／季節窗；**特殊題材掛點的提名加審第五關＝該題材的人工審結論**。

## 9. 驗收斷言建議（RD 開票時掛上）

- 計數誠實：檢視切換三態的計數**總和恆等式**（全部＝官方＋私人）三語斷言；✓○✗×檢視×地區三維疊加後結果集與計數一致。
- 私人徽章永不借用語義色：computed style 斷言 `--cl-grey` 系（badge/地圖釘）；⋯選單刪除項＝唯一紅系。
- 新增流程：DEM 海拔/時區為**唯讀**（`readonly` 斷言）；離群經緯度擋提交（−90/90、−180/180、海拔 sanity）三語 toast。
- 條件表單＝CL-UI-99 同 schema：五組參數 range 驗證共用同一驗證器（重用斷言，不重寫第二套）。
- 刪除確認：明列附掛資料數；確認後提醒停用/評分移除/最愛清除的 DB 效果斷言。
- 額度：滿額 ＋按鈕轉灰＋連結（三語）；GRANDFATHER——額度下調不刪既有點。
- 軟降頻：「節能模式」banner 與「資料更新」實值**同源**斷言（永不靜默）；提醒觸發取數不受降頻影響。
- 提名：提名後 place 狀態機 custom→pending→official/rejected；轉正後評分/提醒/最愛隨帶遷移斷言；不通過退回私人且可再提名（7 天節流）。
- 顯示全寬：quota chip/lat-lng/條件摘要任何數值不省略號（`scrollWidth==clientWidth` 三語斷言，站規）。
